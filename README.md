## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program checks that `entry.png` is a whole PNG or JPEG within the competition's limits, copies it to the output directory, and prints its size, dimensions and sha256.
